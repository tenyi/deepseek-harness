# @deepseek-ai/dsh-client-ui-chat

[English](README.md) | 中文

## 概述

使用本包可在瀏覽器中渲染已記錄的 Session 對話，包括歷史圖片、本地化操作和滾動位置恢復。緊湊顯示會收起已完成輪次的過程行，同時保持最終答案和獨立有用的上下文可見；已打包的歷史 Assistant 連續消息保持收起。本地 transcript（文本記錄）與 steering（中途引導）提交會立即顯示并保留在原區域，在權威會話記錄到達時原子地消失，而排隊中的提交始終不進入 Chat。本包不組裝或修改模型請求。

文件提及提供方同時接收當前查看的會話 ID 與收尾輪次的屬主信息，因此繼承歷史中的鏈接可以指向 fork 自身。

<a id="reference-previews"></a>
## 引用預覽

已發送的文件引用及消息日志確認調用的 skill 可在右側欄打開預覽。文件路徑使用當前查看的 Session；skill 名稱由該 Session 當前的輸入觸發源解析。兩者懸停或聚焦時均使用正文文件鏈接的虛線下劃線。會話、目錄和命令標簽仍只作為引用展示。

<a id="system-prompt-row"></a>
## 系統提示詞行

每個非空追加的 `system/message` 都擁有一行折疊提示詞，包括無 header 窗口起點的完整提示詞；同一步驟的 header 不會重復它。Chat 也會為非空的初始請求、顯式消息序列起點、文本發生變化的 `system/message` surface 節點替換（文本讀取自 `request/header` 處 surface 順序中最后一個非空存活系統節點），或前序 header 尚未進入已加載歷史窗口的非初始請求顯示一行默認折疊的 `系統提示詞`。即使系統文本未變，恢復也會重復該行，包括分頁補齊前序 header 和系統節點后；同一序列內僅配置或僅工具變化、工具步驟與重試不會重復，且 `system/message` 事件絕不會渲染為對話消息。該行位于請求的用戶消息之前，與提供方 envelope 順序一致；展開后顯示模型所見的確切文本，并保留其原始換行。系統節點為空或位于已加載窗口之外的請求不創建該行，直到包含該節點的分頁到達。

<a id="turn-token-usage"></a>
## 輪次 token 用量

只有當已加載窗口包含 `turn/start`，且每次已啟動的模型嘗試都報告安全、精確的用量時，已完成輪次才顯示可展開的用量行。該行會省略不可用的可選用量桶。記賬不完整或相互矛盾時，整個詳情都不顯示，避免把部分總量冒充完整結果。

<a id="completed-turn-footer"></a>
## 已完成輪次的頁腳

已完成輪次的操作頁腳位于前方正文或擴展內容下方 20px。

<a id="turn-process-folding"></a>
## 輪次過程折疊

「設置 → 通用設置」提供持久化到 `ui-chat` 命名空間的「標準」/「緊湊」對話顯示偏好，默認使用「緊湊」。標準模式保持所有過程行可見且不渲染輪次過程控件。緊湊模式下，系統提示詞在整個輪次中始終獨立顯示于開場 User 上方。輪次打開期間，上下文注入、推理、Assistant 內容、工具行與重試行始終展開。到 `turn/end` 時，最后一個步驟只有在包含非空文本、圖片或未知可見塊且不含工具調用塊時才成為最終答案邊界；邊界之前的上下文注入、推理、較早 Assistant 內容、工具行與重試行隨后默認收起。控件展示覆蓋整個輪次的非 subagent 工具調用數、最終答案之前帶回復內容的 Assistant 消息數和 subagent 委派數；值為 0 的分段省略，工具調用與 subagent 兩項互斥，系統提示詞與上下文注入都不增加計數。三項全為 0 時過程仍會收起，控件標題顯示「已思考」（英文為 `Thought for a while`）。摘要下方的通欄分隔線將其與正文或展開后的過程行隔開。用戶與 steering 消息、系統提示詞、錯誤、最大 token 與 turn-tail 行留在過程組外；關閉時沒有最終答案的輪次保留全部過程證據。新的過程控件插入時不會改變既有行的相對順序：開場人工輸入從首次投影起便位于控件和過程行之前，系統提示詞則始終位于該輸入上方。只要仍可通過「加載更早」獲取歷史，過程控件就不出現，也不會隱藏任何成員；歷史加載完整后，每個合格的已關閉輪次立即使用默認收起狀態。穩定 Chat Node Seat 會讓每個 renderer 保持掛載，隱藏成員不產生消息流間距；只有中間沒有獨立輸入時，收起控件才與正文相隔 8px。完成后的收起不依賴是否跟隨尾部，因此正在上方閱讀的用戶可能看到 transcript 重排。若自動收起會隱藏當前鍵盤焦點，則過程組保持展開且焦點留在原處；手動收起會先把焦點移到過程控件，再隱藏成員。會話作用域存儲只記錄用戶手動展開的「輪次 + 正文步驟」generation；不同正文 generation 默認收起。

<a id="scroll-ownership"></a>
## 滾動歸屬

Chat 會在歷史前插與 renderer 重新掛載時恢復語義錨點。沒有讀者移動的貼底滾動事件會立即更新跟隨歸屬，避免后續布局變化使其底部位置失效。讀者移動即使位于跟隨閾值內，也保持待處理直到采樣周期或 `scrollend`，防止布局增長抵消小幅滾動操作。讀者跟隨底部時，`ResizeObserver` 追隨新的底部，并且無需讀取行幾何就選中最后一個已加載輪次；讀者離開底部后，高度變化會保持頂部位置，再由閱讀線幾何選擇活躍輪次。輪次導航預覽位于 Markdown 代碼塊粘性頭欄上方，而導航外框始終處于 composer 上方的 transcript 區域內。

<a id="model-experience"></a>
## 模型體驗

無，因為本包在瀏覽器中渲染已記錄的對話狀態，不注冊任何面向模型的內容。

#### KV Cache 影響

無；Chat 呈現不會組裝或修改提供方請求。

## 已知限制與暫緩事項

<a id="known-limitations-and-deferred-work"></a>

- **transcript 只反映已加載的 Session 窗口**——只有會話控制器加載前一頁事件后，更早的 transcript node 才會出現。輪次導航比窗口更寬：軌道把已加載的輪次與宿主 `turnOutline` 投影合并，每個已開始的輪次都有固定間距刻度（相隔 10px；階梯高于外框時在框內滾動并以漸變淡出標示可滾方向），激活未加載刻度會先把歷史分頁拉到該輪次的 `turn/start` seq 再落到它的行上。沒有該投影時（未掛載 `dsh-session-turn-outline` 的裝配），軌道回退到僅顯示已加載輪次。
- **導航預覽按卡片尺寸截斷**——提示詞一行（50 字符）、回復至多三行（120 字符），已加載與未加載 Turn 一致；未加載 Turn 的回復要等該輪落定后才隨大綱到達，進行中的輪次在此之前只預覽提示詞（或僅輪次號）。
